# Jamie Perrelet

Physicist by training, software engineer by trade. I'm co-founder and technical director of [Digitalis Web Corp](https://digitalis.ca), a studio in Nelson, BC, where we build and run the platforms organisations do their work on: applications on LatticeWP, our own WordPress framework, the servers under them and, since 2026, AI agents working inside them alongside our clients' staff.

## Open source

- **[Sassy](https://github.com/digitalisweb/sassy)**: a rather saucy way of doing SCSS on WordPress. Compiles on the server, models every enqueued stylesheet and writes DevTools edits back into the partial they came from. In production since 2021, GPL since 2026.
- **[glsl-snippets](https://github.com/perrelet/glsl-snippets)**: shader functions for raymarching, noise, SDFs and colour. Painting by numbers was never so easy.
- **[scrub](https://github.com/perrelet/scrub)**: cleans keys, tokens and passwords out of logs before you paste them into an LLM.
- **[md-copy](https://github.com/perrelet/md-copy)**: paste rich text as Markdown on Windows.
